# 四六级学习台

一个纯静态的四六级备考网站：背单词（艾宾浩斯遗忘曲线 + 音标 + 中英例句）、
**634 条考试常用短语**、**语法专项**、作文模板与范文、翻译练习、**听力听写**、
**词汇量自测**、模考计时、错题本、**进度备份**，可**安装到手机并完全离线**使用。
没有后端、不需要安装任何东西。

## 单词是按什么顺序学的

不是字母序，也不是随机序，而是按**考试价值**分三层：

**四级（4544 词）**

| 层 | 内容 | 数量 | 排序依据 |
| --- | --- | --- | --- |
| 1 | 大纲增量词，且命中真题词频表 | 890 | 2020–2025 六级真题 `importance_score` 降序 |
| 2 | 大纲增量词，未命中真题表 | 946 | Google 语料词频降序 |
| 3 | 高中词表里已有的基础词 | 2708 | Google 语料词频降序（放最后） |

**六级（2118 词）**：命中真题表的 586 词优先（按真题重要度），其余 1532 词按通用词频。

设计思路：CET4 大纲 = 高中词汇 + 增量词，真正值得花时间的是增量词。
所以先学"真题里反复出现的高价值词"，把 `of / and / a` 这类谁都会的词排到最后。

实际效果对比：

```
第一层（最先学）  identify · behavior · community · individual · economic · financial · global
第三层（最后学）  kindergarten · handkerchief · granddaughter · pronunciation
```

> ⚠️ 第 2、3 层用到的 Google 词频数据**仅限教育和个人用途，不可商用**，
> 详见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) 第 3 节。


## 部署到 GitHub Pages

不需要安装 Git，全程在网页上完成。

1. **新建仓库** —— 打开 [github.com/new](https://github.com/new)，仓库名填 `cet`（或任意名字），
   可见性选 **Public**，点 Create repository。

2. **上传文件** —— 在仓库页点 **Add file → Upload files**。
   打开本地的 `cet-site` 文件夹，**选中里面全部内容**
   （`index.html`、`manifest.json`、`sw.js`、`assets` 文件夹、`data` 文件夹、`icons` 文件夹、
   `README.md`、`THIRD-PARTY-NOTICES.md`）
   一起拖进上传区域，然后点 **Commit changes**。

   > ⚠️ 注意拖的是**文件夹里面的内容**，不是 `cet-site` 文件夹本身。
   > 如果多套了一层，网站会打不开。
   >
   > ⚠️ `manifest.json`、`sw.js` 和 `icons/` 缺一不可，否则「安装到手机」和离线都会失效。

3. **开启 Pages** —— 进仓库 **Settings → Pages**，
   Source 选 `Deploy from a branch`，Branch 选 `main` + `/ (root)`，点 Save。

4. **等待约 1 分钟**，访问 `https://你的用户名.github.io/cet/`

5. **（可选）安装到手机** —— 用手机浏览器打开上面的网址，按「手机上安装」一节的步骤操作。

> 更新网站后，Service Worker 会在你下次打开时自动拉取新版本。
> 如果发现还是旧界面，刷新两次即可（第一次在后台更新缓存，第二次生效）。

## 关于学习进度

- 所有进度（学习记录、错题、设置）都存在**你本机浏览器的 localStorage** 里，
  不会上传到任何服务器，换设备或换浏览器都看不到对方的进度。
- **清除浏览器数据会丢失进度**，所以「今日 → 学习设置」里提供了
  **导出 / 导入学习进度**（见下一节）。

> 也可以直接双击本地的 `index.html` 离线使用，功能完整、学习进度能正常保存
> （已在 Edge 下完整验证：176 项功能测试 + 24 项离线测试全部通过）。
> 但此时地址是 `file:///D:/...`，**与线上版本的进度互相独立**，两边数据不互通。

## 进度备份怎么用

「今日 → 学习设置」底部有两个按钮：

| 按钮 | 作用 |
| --- | --- |
| **导出学习进度** | 下载一个 JSON 文件，包含全部单词记录、错题、学习历史、连续天数、翻译练习、真题错题、词汇量测试历史 |
| **导入学习进度** | 选择之前导出的 JSON，**合并**进当前记录 |

**导入是合并，不是覆盖。** 规则：

- 同一个单词，保留**更成熟**的复习阶段（阶段相同则取更晚的记录）
- 错题次数取两者较大值
- 学习历史按天取较大值，不会重复累加
- 真题错题、词汇量历史按 ID / 时间戳去重后合并

所以它可以放心用在两种场景：

1. **防丢**：清缓存、换浏览器前导出一份，之后导入回来
2. **两台设备合并**：手机和电脑各导出一份，互相导入一次，两边就都有完整记录

> 导出文件是**明文 JSON**，不加密、也不上传。里面只有学习记录，没有个人信息。

## 遗忘曲线是怎么工作的

每个词有 10 个复习阶段，间隔依次为：

```
5分钟 → 30分钟 → 12小时 → 1天 → 2天 → 4天 → 7天 → 15天 → 30天 → 已掌握
```

每答完一题，你选择对词的熟悉程度，决定它下次什么时候出现：

| 选择 | 效果 |
| --- | --- |
| 忘记 | 打回 5 分钟档，并自动记入错题本 |
| 模糊 | 退一个阶段，缩短间隔 |
| 认识 | 前进一个阶段 |
| 熟练 | 跳过一阶段 |

间隔在 30 分钟以内的词，会在**本轮学习中重新出现一次**（当堂重复，符合艾宾浩斯原理），
但每个词最多重插 2 次，避免反复答错时这一轮永远结束不了。

### 三个防止「自欺欺人」的机制

**① 已会的词可以一键跳过。**
答题时卡片下方有「我早就会了，标记为已掌握」。点了直接记入已掌握档（90 天后再见），
同时从错题本里移除——不必为了一个早就认识的词白走 10 个阶段。

**② 「熟练」跳级有门槛。**
四选一的蒙对概率是 25%，全靠自评会让没掌握的词被推到 30 天后。所以

- **这个词以前答错过**，或
- **本次作答超过 6 秒**（说明在犹豫/排除法）

满足任一条，「熟练」按钮就会变灰，只能记到「认识」为止，并在下方说明原因。
拼写和听写模式不受时间限制——那两种模式没法蒙。

**③ 复习积压会明确告诉你。**
到期词超过「复习上限」时，界面上会写明：

> 本轮最多安排 **120** 个到期词（复习上限 120），另有 **180** 个会顺延到下一轮，不会丢失。

不会出现「首页写 300、实际只做 120、剩下的不知去向」这种困惑。

## 作文范文怎么用

「作文 → 完整范文」里有 6 篇成篇范文（观点对比、现象解释、图表、应用文、谚语、六级各一篇），
每篇包含：

- **英文全文**：先自己读一遍，看模板句型在真实文章里长什么样
- **中文译文**：默认隐藏，点按钮才显示，方便先自己理解
- **值得背下来的句子**：5 条逐句点评，说明这句为什么好、好在哪里

建议顺序：先看「模板框架」记住结构 → 读范文 → 挑 3–5 个句子背下来 → 自己动笔写。

## 翻译练习怎么用

「翻译 → 翻译练习」是**动手写**的模式，不是看：

1. 屏幕给出中文句子
2. 在输入框里写下你的英文翻译
3. 点「对照参考答案」
4. 系统会**比对你漏掉了哪些关键词**（机器粗略比对，不是评分）
5. 自评「掌握了」或「还要再练」——选后者会自动排回队列再练一次

进度按题目分别记录。已经掌握的题会统计在顶部的范围筹码里，
可以只挑「传统节日」或「科技成就」单独练。

> 关键词比对只检查实义词是否出现，**不判断语法、时态、冠词是否正确**。
> 这些要自己对着参考答案再读一遍。界面上也写了这个提醒，别被 10/10 骗了。

## 高级替换词怎么用

「作文 → 高级替换词」共 **75 组对照、236 个表达**，按词性分 5 类：

| 分类 | 组数 | 表达数 | 说明 |
| --- | --- | --- | --- |
| 动词 | 25 | 83 | 把 get / make / help 这类「万能动词」换成精确的书面动词 |
| 形容词 | 20 | 67 | 描述性质的地方，最容易被阅卷老师看到 |
| 副词与程度 | 10 | 28 | very / really 是最典型的低分表达 |
| 名词 | 10 | 34 | 让主语宾语更准确、更书面 |
| 短语与句式 | 10 | 24 | 整句替换，比只换单词更能提分 |

其中 **14 条带 ⚠ 的用法提示**，都是扣分频率最高的地方，例如：

- `a great deal of` **只修饰不可数名词**，写成 a great deal of students 会被扣分
- `be of great significance` **介词用 to**，不是 for
- `utilize` 正式度很高，简单语境硬用反而别扭——**别为了高级而滥用**
- `give rise to` 后面接**结果、现象**，不接人

背之前先看提示，比多背 50 个词更值。点任意词即可复制。

## 单词例句怎么用

词库里 **4382 个单词带中英例句**，在三个地方都能看到：

- **背单词答题后**：答对或答错，反馈里都会出现例句和译文，可以点「🔊 朗读例句」
- **词库浏览**：每条词下面直接显示例句
- **错题本**：复习错词时同样能看到

例句有两个来源：

| 来源 | 数量 | 特点 |
| --- | --- | --- |
| Tatoeba 真实语料 | 3466 | 地道自然，但偏口语 |
| 本项目手写 | 916 | 学术语域，贴近四六级阅读真题 |

**为什么手写了一部分**：按学习顺序最靠前的 916 个核心学术词
（`significant`、`facilitate`、`priority`、`sustainable` 等）恰恰是口语语料里最缺的，
而它们又是最该学的。所以这部分由我逐条编写，语域刻意贴近考试。

结果：**学习顺序最靠前的核心词 100% 有例句**，越往后覆盖率递减
（四级第 1201-1836 名只有 32%）。没有例句的词就不显示，不硬凑。

## 考试常用短语怎么用

「短语」标签页里有 **634 条**，按类型分成 5 类：

| 分类 | 条数 | 说明 |
| --- | --- | --- |
| 介词短语 | 278 | 考试里出现频率最高，注意 in / on / at / out of 的区别 |
| 动词短语 | 157 | 有独立引申义的短语动词，阅读和完形高频考点 |
| 固定搭配与习语 | 155 | 不能按字面理解，只能整体记忆 |
| be + 形容词 + 介词 | 26 | 写作最常被扣分的地方：形容词后接哪个介词 |
| 名词短语与量词 | 18 | 写作和翻译里顺手就能用 |

两个实用功能：

- **中英搜索**：输入 `in vain` 或「遵守」都能查到
- **遮住释义自测**：勾选后所有中文释义变模糊，先自己想意思，点一下才显示

> 原始候选表有 4174 条，但里面混了大量机械组合（`box in`、`key in`、`pack in`）
> 和生僻俚语。我做了筛选，只保留真正有考试价值的，并补上了源表遗漏的高频短语
> （`turn out`、`break down`、`look forward to` 等）。中文释义全部重新编写。

## 音标怎么显示

词库里 **6645 / 6662 词（99.7%）带 IPA 音标**，三个地方都能看到：

- **背单词答题时**：单词下方直接显示音标
- **词库浏览**：每个词旁边显示
- **词汇量自测**：测试词也带音标

音标来自 [open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict)（MIT）。
一词多音时只保留最常见读音；英式拼写（`gaol`、`vapour`）在构建阶段映射到美式拼写查询。

> 音标只是辅助，**发音还是听 TTS**——IPA 符号看得懂不等于读得准。

## 听力听写怎么用

「背单词 → 练习模式 → 听力听写」是五种模式里唯一练**句子听力**的：

1. 系统朗读一句英文（自动播一次，可重播）
2. 你用键盘把听到的内容写下来
3. 提交后按**词**比对，给出正确率
4. 正确率 ≥60% 记为通过，并显示原文、译文和这个词的释义

三个辅助按钮：

| 按钮 | 作用 |
| --- | --- |
| 🔊 播放句子 | 用正常速度重播 |
| 🐢 慢速 | 降到 0.6 倍速，适合一开始跟不上 |
| 单听这个词 | 只念目标单词，帮你定位关键信息 |

**设计说明**：听写素材复用已有的 4382 条例句，不额外引入音频文件，
所以零流量、可离线。优先安排有例句的词；没有例句的会退化成单词听写。
评分只按词比对，拼错个别字母不影响，重点在「听没听出来」。

## 词汇量自测怎么用

「今日 → 词汇量自测」按钮，从**四个频段**各抽 15 个词，共 60 个：

- 只回答「认识 / 不认识」，不用写意思，凭第一反应
- 测完给出估算词汇量、四个频段的掌握率、对应的备考建议

**怎么理解这个结果**：它测的是「**认不认识**」，没测「会不会用」。
真实考试还涉及搭配、语感和阅读速度，所以数字只作参考，别当成绝对水平。
不确定的词建议点「不认识」——虚高会低估你实际需要补的量。

## 语法专项怎么用

「语法」标签页有 6 个专题，覆盖四六级阅读、翻译、写作共同的底层考点：

| 专题 | 核心考点 |
| --- | --- |
| 定语从句 | 关系词选择、限制性 vs 非限制性、介词 + which/whom |
| 非谓语动词 | to do / doing / done 的区别、悬垂结构、独立主格 |
| 虚拟语气 | 三种时间条件句、should 型虚拟、if 省略倒装 |
| 倒装句 | 否定词置首、Only + 状语、so/neither |
| 名词性从句 | that vs what、it 作形式主语、同位语从句 |
| 主谓一致 | 就近原则、集合名词、易混淆复数 |

每个考点都按「**规则 → 正确例句（带点评）→ 常见错误**」组织。
常见错误用 ✗ / ✓ 对照呈现，比只看正确句子更容易发现自己哪里想错了。

## 常见问题

**打开是 404？**
检查 Pages 设置页顶部有没有绿色的 "Your site is live at..."。没有就再等两分钟。
确认文件名是**小写** `index.html`，GitHub Pages 的服务器区分大小写。

**发音没声音？**
发音调用的是浏览器和操作系统的内置语音包，不需要联网也不加载音频文件。
如果没声音，检查系统音量，或换 Chrome / Edge。部分 Linux 系统默认没装英文语音包。

**一轮有多少个词？**
默认复习到期词（上限 120 个）+ 新词 20 个，可在「今日 → 学习设置」里调整，
新词量建议 15–30 个，贪多会导致第二天的复习量雪崩。

**题库里没有真题？**
真题受版权保护，不能直接内置。错题本模块提供了手动记录真题错题的功能，
可以把做错的题目、自己的答案和反思记进去，考前集中回看，并支持导出为 txt。

## 想替换、扩充或重新排序词库

排序由构建目录的 `build.js` 生成，它需要 4 份外部数据：

| 文件 | 来源 | 用途 |
| --- | --- | --- |
| `cet4.json` / `cet6.json` | [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary) | 单词、词性、释义、词组 |
| `cet6_exam_freq.csv` | [wangjiuyi543-ui/cet6-vocabulary](https://github.com/wangjiuyi543-ui/cet6-vocabulary) | 真题词频，决定第一层排序 |
| `freq_google10k.txt` | [first20hours/google-10000-english](https://github.com/first20hours/google-10000-english) | 通用词频，决定第二、三层排序 |
| `senior_high.txt` | KyleBing 仓库的 `2 高中-乱序.txt` | 识别"已知基础词"，排到最后 |

把这些文件放进构建目录，然后运行：

```bash
node build.js
```

脚本会重新生成 `data/cet4.js` 和 `data/cet6.js`，
并在结束时**读回落盘文件逐项校验**（词数、首词、末词），不一致会直接报错退出。

也可以手工增补词条，数据结构很简单：

```js
// [单词, 词性, 中文释义, 词组搭配(可选)]
["abruptly", "adv.", "突然地", null]
```

> 手工改完词库后，**不要把已经学过的词顺序打乱**——学习进度是按单词本身记录的，
> 不依赖顺序，所以增删词条不会丢进度。但如果删掉某个词，它的学习记录会变成孤儿数据（无害）。
